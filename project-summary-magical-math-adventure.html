เพิ่มเกมผจญภัยดินแดนเวทมนตร์คณิตศาสตร์แล้ว

อัปเดตคลังสื่อห้องเรียนครูนิอาดีลา วันที่ 13 กรกฎาคม 2569

สิ่งที่ผู้เรียนได้รับ

ผู้เรียน ป.3-6 สามารถฝึกบวก ลบ คูณ และหารผ่านด่านแฟนตาซี 5 ด่าน มีคะแนน คอมโบ พลังวิเศษ ตัวจับเวลา และระดับความยากให้ครูปรับตามห้องเรียน

สิ่งที่เพิ่มในเว็บไซต์

  • การ์ดเกมใหม่พร้อมภาพจริงในหน้าแกลเลอรี
  • หน้าเล่นเกมแบบ static ที่ apps/magical-math-adventure/index.html
  • รองรับหน้าจอ desktop และโทรศัพท์มือถือ
  • แสดงในตัวกรอง ป.3-4 และ ป.5-6 ตามระดับเริ่มต้นของโจทย์

ผลตรวจรับ

ทดสอบเปิดจากแกลเลอรี กรอกชื่อ เริ่มเล่น ตอบโจทย์ถูก และยืนยันว่าคะแนน คอมโบ และลำดับข้ออัปเดตตามจริง ตรวจทุกเส้นทางเกมได้ HTTP 200 และไม่พบข้อผิดพลาดใน console ของเกม

ข้อควรทราบ

เกมถูกแปลงจากระบบ vinext เป็นไฟล์ static เพื่อให้เข้ากับเว็บไซต์นี้ หากต้นทางสร้าง build ใหม่ ควรนำเข้าใหม่และตรวจ asset path ซ้ำ ส่วนฟอนต์ออนไลน์มี fallback จึงยังอ่านและเล่นได้หากเครือข่ายโรงเรียนบล็อก Google Fonts
