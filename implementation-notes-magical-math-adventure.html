บันทึกการเพิ่มเกมผจญภัยดินแดนเวทมนตร์คณิตศาสตร์

สถานะ: ดำเนินการและตรวจสอบเสร็จแล้ว

ขอบเขตจากคำขอ

นำเกมจากโฟลเดอร์ต้นทางเข้าคลังสื่อ NiadeelaClass เชื่อมจากหน้าแกลเลอรี ตรวจสอบเส้นทางและการเล่น แล้วจัดทำหลักฐานการทดสอบ

หลักฐานและการตัดสินใจระหว่างทำ

  • ต้นทางเป็น vinext/React และ build ที่ dist/client ไม่มี index.html เพราะหน้าเว็บถูก render ผ่าน worker จึงใช้ HTML ที่ worker render จริงเป็น static entry point
  • เลือก route apps/magical-math-adventure/index.html ให้สื่อความหมายตรงกับชื่อและไม่ชนกับเกมเดิม
  • ปรับ asset URL จาก root-relative เป็น route-relative เพื่อให้เกมทำงานใต้โฟลเดอร์ของ static portfolio
  • vinext preload runtime เติมเครื่องหมาย / หน้า asset และ CSS custom property resolve ภาพจากตำแหน่ง stylesheet จึงปรับสองจุดนี้แยกกันหลัง QA พบ 404; ไม่คัดลอกภาพซ้ำเพื่อลดขนาดและรักษา DRY
  • รอบ code review ย้าย OG image ไปใช้ไฟล์กลางเดียวกับ thumbnail, ตัดฟอนต์ build ที่ไม่ถูกอ้างถึง และวาง script ไว้ก่อนปิดเอกสารให้ semantic พร้อม font fallback ตามมาตรฐานรีโป
  • คง generated HTML ส่วนเนื้อหาเกมเป็นรูปแบบ minified เพราะการจัด whitespace แบบ HTML ทั่วไปทำให้ React hydration mismatch; นี่เป็นข้อยกเว้นจากกฎเยื้อง 2 ช่องสำหรับ build artifact เท่านั้น ส่วนไฟล์ที่ดูแลด้วยมือยังใช้รูปแบบของรีโป
  • เกมมีระดับง่าย ปานกลาง ยาก และฝึกบวก ลบ คูณ หาร แต่ระดับเริ่มต้นมีจำนวนถึงหลักร้อยและสูตรคูณ 12 จึงจัดการ์ดไว้ในตัวกรอง ป.3-6; ครูยังลดเป็นระดับง่ายสำหรับผู้เรียนที่อายุน้อยกว่าได้ภายในเกม
  • ใช้ภาพ Open Graph ของเกมจริงเป็น thumbnail แทนภาพ placeholder

การตรวจสอบ

  • ต้นทางผ่าน npm test (2 tests), npm run build และ npm run lint
  • Playwright เปิดเกมจากหน้าแกลเลอรี เติมชื่อ เริ่มด่าน 1 และตอบ 68 + 103 = 171; คะแนนเพิ่มเป็น 136 เหรียญเป็น 70 คอมโบเป็น 1 และเกมไปข้อ 2
  • เกมที่ desktop 1440 × 1024 และ mobile 390 × 844 โหลด asset ครบและไม่มี console error; mobile มี scrollWidth = innerWidth = 390
  • จำลอง Google Fonts ตอบ HTTP 503 แล้วหน้า mobile ยัง hydrate สำเร็จ เริ่มเกมได้ และไม่มี horizontal overflow จึงยืนยัน font fallback ตามมาตรฐานรีโป
  • ตัวกรองยืนยันว่าการ์ดใหม่ซ่อนใน ป.1-2 และแสดงใน ป.3-4, ป.5-6 และผลงานทั้งหมด
  • หน้าเกมทั้ง 8 route ตอบ HTTP 200; หน้าแกลเลอรีมีเพียง /favicon.ico 404 เดิมที่ไม่กระทบเกม
