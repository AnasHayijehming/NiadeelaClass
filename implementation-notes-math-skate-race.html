บันทึกการเพิ่มเกม Math Skate Race Adventure

สถานะ: ดำเนินการและตรวจสอบเสร็จแล้ว

ขอบเขตจากคำขอ

นำเกมจากโฟลเดอร์ต้นทางเข้าคลังสื่อ NiadeelaClass เชื่อมจากหน้าแกลเลอรี ตรวจสอบการใช้งาน แล้ว commit และ push

หลักฐานและการตัดสินใจระหว่างทำ

  • ต้นทางเป็น React/vinext แต่ปลายทางเป็น static portfolio จึงต้องจัดแพ็กเป็น static client bundle ที่เปิดจากโฟลเดอร์ย่อยได้
  • แยกขอบเขตจากงาน neon-math-racer ที่มีอยู่แล้ว โดยไม่แก้ไฟล์ของเกมดังกล่าว
  • เกมรองรับระดับ ป.1-4 จึงจัดให้อยู่ในตัวกรอง ป.1-2 และ ป.3-4
  • เปลี่ยน asset URL ของเกมจาก root-relative เป็น relative เพื่อให้ deploy ใต้ apps/math-skate-race/ ได้โดยไม่ต้องมี server rewrite
  • นำเข้าเฉพาะ static client bundle และภาพที่เกมใช้ ไม่รวม worker, ฐานข้อมูล, source repository หรือ node_modules

การตรวจสอบ

  • Production client build ผ่านด้วย Vite 8.0.13
  • เปิดจากหน้า gallery และ route เกมผ่าน HTTP static server ได้
  • Playwright ยืนยัน flow: เริ่มเล่น → เลือก ป.1 → เลือกนักแข่ง/ด่าน → ตอบถูก → คะแนน 100 และ COMBO 1
  • ตรวจภาพ desktop 1440 × 1024 และ mobile 390 × 844 แล้วไม่พบข้อความหรือปุ่มซ้อนกัน
  • Regression pass ครบ filter ทั้ง 4 สถานะ และเปิด app route ครบทั้ง 6 การ์ดผ่าน browser
  • ESLint ของโปรเจกต์ต้นทางผ่าน ส่วน npm test build ผ่านแต่ test 2 รายการล้มเหลว เพราะยังตรวจหน้า starter skeleton ที่ถูกแทนด้วยเกมแล้ว ไม่ใช่ข้อผิดพลาดของ static bundle ที่นำเข้า
  • พบเพียง /favicon.ico 404 เดิมของหน้า portfolio ไม่กระทบเกม
