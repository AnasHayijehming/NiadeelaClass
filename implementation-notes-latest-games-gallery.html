บันทึกการทำงาน: แกลเลอรีเกมล่าสุด

เริ่มบันทึกวันที่ 13 กรกฎาคม 2569 ระหว่างปรับหน้าแกลเลอรีหลัก

การตัดสินใจที่ไม่มีระบุในโจทย์

  • ใช้เวลาจาก commit ที่เพิ่มเกมเป็นหลักฐานของคำว่า “ล่าสุด” และบันทึกใน data-added
  • เมื่อเปลี่ยนตัวกรอง จะเริ่มแสดง 4 เกมแรกของหมวดนั้นใหม่ เพื่อไม่ให้สถานะจากหมวดก่อนหน้าทำให้รายการยาวเกินคาด
  • ซ่อนปุ่มขยายเมื่อแสดงครบแล้ว และเพิ่มข้อความบอกจำนวนเกมที่กำลังแสดงสำหรับผู้ใช้และโปรแกรมอ่านหน้าจอ

ข้อแลกเปลี่ยน

วันที่เพิ่มเกมถูกเก็บใน HTML โดยตรง ทำให้ static site ไม่ต้องมี backend แต่ผู้เพิ่มเกมใหม่ต้องใส่ data-added ให้ถูกต้อง

สถานะการตรวจสอบ

  • หน้าแรกแสดง 4 เกมล่าสุดตามลำดับ Magical Math, Long Division, Math Skate และ Neon Math Racer
  • กดขยายหนึ่งครั้งแล้วแสดงครบ 8 เกม และปุ่มขยายซ่อนเมื่อไม่มีรายการเหลือ
  • ตัวกรอง ป.1-2 แสดง 2 จาก 2 เกม และซ่อนปุ่มขยาย
  • ตรวจ desktop 1440 × 1000 และ mobile 390 × 844 แล้ว ไม่พบ horizontal overflow หรือองค์ประกอบซ้อนกัน
  • เส้นทางเกมทั้ง 8 รายการตอบ HTTP 200; console หน้าแกลเลอรีพบเพียง /favicon.ico 404 ที่มีอยู่เดิม
