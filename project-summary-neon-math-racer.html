เพิ่มเกมซิ่งคูณสนั่นในเว็บไซต์ชั้นเรียน

เพิ่มเกมฝึกสูตรคูณธีมแข่งรถสำหรับนักเรียน ป.3-6 พร้อมการ์ดใหม่ในหน้าแกลเลอรีและเส้นทางเข้าเล่นโดยตรง

ประโยชน์

นักเรียนได้ฝึกสูตรคูณผ่านการตอบคำถามแบบรวดเร็ว มีตัวละครและบรรยากาศการแข่งขันช่วยเพิ่มแรงจูงใจ

ขอบเขตและการตัดสินใจ

นำเฉพาะ production build ที่พร้อมเผยแพร่เข้าระบบ ไม่เพิ่มเครื่องมือพัฒนาหรือ dependency ขนาดใหญ่ในเว็บไซต์หลัก และปรับ path ให้ทำงานภายใต้โฟลเดอร์ย่อยได้

การตรวจสอบ

ตรวจ syntax/build artifact, route จากหน้าแกลเลอรี, การโหลด asset และทดลองการโต้ตอบทั้ง desktop กับ mobile ก่อนเผยแพร่

ความเสี่ยงและข้อเสนอแนะ

เกมเป็น bundle ที่ build แล้ว จึงแก้ไขภายในได้ยากกว่าเกม HTML/JavaScript เดิม หากต้องพัฒนาต่อควรเก็บ source project แยกไว้และ build ใหม่ทุกครั้ง

อัปเดตรอบล่าสุด — 10 กรกฎาคม 2569

เกมเพิ่มนักแข่งใหม่เป็น 6 ตัว ได้แก่ สุนัขจรวดและเพนกวินเจ็ต ปรับการเลี้ยวให้แม่นยำขึ้น เพิ่มเสียงเครื่องยนต์และเสียงตอบสนอง พร้อมลดขนาดภาพตัวละครด้วย WebP เพื่อให้โหลดเร็วขึ้น

แพ็กเกจใหม่ของต้นทางรองรับระบบโฮสต์เฉพาะ แต่เว็บไซต์นี้ยังคงใช้เฉพาะส่วน client แบบ static เพื่อรักษาการเผยแพร่เดิมและลดความซับซ้อน
