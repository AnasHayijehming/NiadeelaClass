เพิ่มเกม “สเก็ตซิ่งพิชิตคณิต” เข้าคลังสื่อ

นักเรียน ป.1-4 สามารถเปิดเกมจากหน้าแฟ้มผลงาน เลือกระดับชั้น นักแข่ง และสนาม แล้วฝึกคณิตศาสตร์ผ่านการแข่งขันได้ทันที

สิ่งที่เปลี่ยน

  • เพิ่มการ์ดเกมพร้อมภาพตัวอย่างและตัวกรองระดับ ป.1-4
  • เพิ่มเกมแบบ static ที่ apps/math-skate-race/index.html
  • คงระบบคะแนน คอมโบ ชีวิต ตัวละคร 8 แบบ สนาม 4 แบบ สถิติ และกระดานผู้นำบนอุปกรณ์

ผลกระทบและการตัดสินใจ

เกมต้นทางใช้เทคโนโลยีที่ต้องมี server แต่เว็บไซต์ครูเป็น static portfolio จึงแปลงเฉพาะส่วนที่ผู้เรียนใช้งานเป็น static client bundle ทำให้เปิดจากโฮสติ้งเดิมได้โดยไม่เพิ่มระบบหลังบ้านหรือภาระดูแล server

ผลตรวจรับ

  • เปิดจากหน้าแกลเลอรีและโหลดภาพเกมครบ
  • ทดสอบการเลือกระดับ ป.1 นักแข่ง สนาม และตอบโจทย์ถูกจนคะแนน/คอมโบเพิ่ม
  • ตรวจหน้าจอ desktop 1440 × 1024 และมือถือ 390 × 844 แล้วใช้งานได้
  • ตรวจตัวกรองทุกระดับชั้นและเปิดเกมเดิมทุกการ์ดเพื่อป้องกันผลกระทบย้อนหลัง
  • ไม่พบข้อขัดข้องของเกม มีเพียง favicon 404 เดิมของเว็บไซต์ซึ่งไม่กระทบการเรียน

ข้อเสนอแนะถัดไป

ควรให้ครูทดลองโจทย์แต่ละระดับชั้นกับนักเรียนกลุ่มเล็ก เพื่อปรับระดับความยาก เวลาอธิบาย และคำศัพท์ให้เหมาะกับชั้นเรียนจริง
