บันทึกการเพิ่มเกม Long Division Adventure

สถานะ: ดำเนินการและตรวจสอบเสร็จแล้ว

ขอบเขตจากคำขอ

นำเกมจากโฟลเดอร์ต้นทางเข้าคลังสื่อ NiadeelaClass เชื่อมจากหน้าแกลเลอรี ตรวจสอบการใช้งาน แล้ว commit และ push

หลักฐานและการตัดสินใจระหว่างทำ

  • ต้นทางเป็น HTML ไฟล์เดียว จึงคัดลอกเข้า apps/long-division-adventure/index.html โดยตรง และตรวจ SHA-256 ตรงกับต้นฉบับ
  • เกมระบุผู้เรียน ป.4 จึงจัดการ์ดในตัวกรอง ป.3-4 เท่านั้น
  • สร้าง thumbnail จากหน้าเริ่มต้นของเกมจริงแล้ว โดยไม่ใช้ภาพ placeholder
  • โหมด AR Hand ต้องใช้ HTTPS/localhost, สิทธิ์กล้อง และ MediaPipe CDN; โหมดอื่นไม่ต้องใช้กล้อง

การตรวจสอบ

  • หน้าเกมและไฟล์ static ตอบ HTTP 200
  • Playwright ยืนยัน flow: เริ่มการผจญภัย → ฝึกฝน → ตอบ 3 ÷ 2 = 1 → คะแนนเพิ่มเป็น 10 → โจทย์เดินต่อ
  • ตรวจ desktop 1440 × 1024 และ mobile 390 × 844 แล้วไม่พบข้อความหรือปุ่มซ้อนกัน
  • Regression pass ครบ filter ทั้ง 4 สถานะ และเปิด app route ครบทั้ง 7 การ์ด
  • ไม่พบ console error ของเกม; พบเฉพาะ /favicon.ico 404 เดิมของ portfolio
  • ไม่ได้อนุญาตสิทธิ์กล้องระหว่าง QA จึงยังไม่ได้ตรวจ gesture จริงของ AR Hand บนอุปกรณ์จริง
